# C Systems Practice

This repository contains my personal C practice exercises focused on low-level programming and systems concepts.

## Purpose

The goal of this repository is to strengthen my understanding of C programming, memory management, data structures, Linux systems programming, and debugging.

This repository is part of my preparation for software engineering roles in systems programming, embedded software, and security.

## Topics Covered

- Pointers and pointer arithmetic
- Memory management
- Arrays and strings
- Structs
- Bit manipulation
- Data structures
- Linux systems programming
- Debugging with tools such as GDB and Valgrind
