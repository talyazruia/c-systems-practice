# Swap With Pointers - Notes

In this exercise, I practiced passing variables by address using pointers.

A pointer stores the memory address of another variable.
Dereferencing a pointer with `*` allows access to the value stored at that address.

The `swap` function receives two integer pointers and swaps the values stored in those addresses.

Important:
- `&x` gives the address of `x`.
- `p` stores an address.
- `*p` accesses the value at that address.
